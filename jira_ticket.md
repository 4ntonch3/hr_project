# Подзадача. Необходимо обновлять модели управляющих структур после окончания ELT-процессинга

## Краткое описание

После окончания ELT процессинга необходимо обновлять данные по Системам и Стендам на основании новых данных.

Что обновляется:

- Создаются новые Системы
- Создаются новые Стенды
- Обновляется статус существующей Системы
- Обновляется статус существующего Стенда
- Обновляются IP-адреса существующего Стенда

## Критерии приемки

- [ ] Обновление не должно быть остановлено, если случилась ошибка обработки для одной из структур
- [ ] Ошибки обработки выведены в stdout
- [ ] Функциональность покрыта автоматическим тестированием
