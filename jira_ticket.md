# Задача №1. Как пользователь хочу активировать Сетевое Взаимодействие, чтобы получить сетевой доступ

## Краткое описание

После создания Сетевого Взаимодействия любой пользователь может его активировать с целью получения сетевого доступа.

Перед активацией необходимо выполнить проверки. В случае ошибки необходимо вывести поясняющий текст для пользователя. Проверки:

1. Сетевое Взаимодействие должны быть актуальным
2. В Сетевом Взаимодействии есть хотя бы по 1 подтвержденному IP-адресу с каждой стороны взаимодействия

Сетевое Взаимодействие не может быть активировано более чем 1 раз.

## Контракт

Входные данные:

- ID Сетевого Взаимодействия

Выходные данные:

- В случае успеха - отсутствуют
- В случае неудачи - ошибка (формат не указан)

## DoD

- [ ] Пользователь может активировать Сетевое Взаимодействие
- [ ] В случае ошибки при активации Пользователь получает сообщение с ошибкой. В сообщении есть информация о причине ошибки
- [ ] Сохраняется информация о пользователе, который активировал Сетевое Взаимодействие
- [ ] Функциональность покрыта автоматическим тестированием
